# Projeto-Validade

Esse é um projeto focado no desenvolvimento de uma solução para um dos vários problemas do varejo. Ele foi feito para ser apresentado na EXPOAGAS 2026, feito em parceria com a UniRitter.

O projeto consiste em um site feito com HTML, CSS e JavaScript. A ideia principal é ser um sistema que calcula o vencimento de produtos em estoque no mercado e com o uso de um inteligência artificial, gera uma proposta de desconto, combo ou promoção para evitar a perda de dinheiro.

Por exemplo, um iogurte de 6 reais está a 1 dia do vencimento, a IA gera uma ideia de desconto de 40% por exemplo, ou um combo como "leve 2 por 1".

O site mostra o total de desperdício evitado, tanto em dinheiro quanto em kg, mostra os benefícios ESG.

Em futuros próximos, a ideia pode ser implementada em projetos maiores, como um site de gerenciamento de estoque geral, gerenciamento financeiro e pode ser implementado junto a um aplicativo/site de compras para o mercado de forma online, para traçar os produtos mais comprados e os menos comprados, ajudando mais ainda a evitar o desperdício, pois menos itens chegariam ao final do estoque perto do vencimento.
